================================================================
  SPRINGFIELD STATE UNIVERSITY PORTAL — SETUP WALKTHROUGH
================================================================

This is a deliberately vulnerable Next.js app hosted on Vercel
with Supabase PostgreSQL as the database backend. It demonstrates
OWASP Top 10 vulnerabilities A01, A02, and A07 for security
education.

================================================================
1. CREATE A SUPABASE PROJECT
================================================================

  1. Go to https://supabase.com and sign up / sign in
  2. Click "New project"
  3. Name: "ssu-portal" (or any name you like)
  4. Set a secure database password (save it somewhere)
  5. Region: choose one closest to you
  6. Click "Create new project" (takes ~1-2 minutes)

================================================================
2. RUN THE SCHEMA + SEED SQL
================================================================

  In your Supabase dashboard:
    → Go to "SQL Editor" (left sidebar)
    → Click "New query"
    → Open the file  supabase/schema.sql  from this project
    → Paste and RUN it
    → Open the file  supabase/seed.sql  from this project
    → Paste and RUN it

  This creates the tables and seeds them with demo data.

================================================================
3. GET YOUR API CREDENTIALS
================================================================

  In your Supabase dashboard:
    → Go to "Project Settings" → "API"
    → Copy the "Project URL" (looks like https://xxxxx.supabase.co)
    → Copy the "anon public" key (starts with eyJ...)

================================================================
4. SET UP ENVIRONMENT VARIABLES
================================================================

  Rename .env.local.example to .env.local and fill in your values:

    NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
    NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here

================================================================
5. RUN LOCALLY
================================================================

    npm run dev

  The app runs at http://localhost:3000

================================================================
6. DEPLOY TO VERCEL
================================================================

  1. Push this project to a Git repository (GitHub/GitLab)
  2. Go to https://vercel.com and import the repository
  3. Add these environment variables in Vercel project settings:
       - NEXT_PUBLIC_SUPABASE_URL
       - NEXT_PUBLIC_SUPABASE_ANON_KEY
  4. Deploy — Vercel auto-detects Next.js

8. VULNERABILITIES (for security education)
================================================================

  A01 - Broken Access Control:
    • IDOR: /profile/:id, /grades/:id, /transcript/:id — view ANY user
    • No role checks on /admin, /it/dashboard, /lecturer/grades
    • Mass assignment on profile edit — change 'role' to escalate
    • Open API: /api/users, /api/courses, /api/enrollments (no auth)

  A02 - Cryptographic Failures:
    • MD5 password hashing (intentionally weak)
    • Plaintext passwords in plain_password column
    • All credentials leaked in /robots.txt
    • Weak JWT secret: 'spr1ngf13ld_s3ss10n'

  A07 - Identification & Auth Failures:
    • Hardcoded JWT secret (forgeable tokens)
    • httpOnly:false cookies (XSS can steal tokens)
    • Remember-me cookie = base64(userId) (trivially forgeable)
    • No rate limiting on login
    • Predictable password reset tokens (MD5 + timestamp)

  Extra:
    • /.env — fake environment variables exposed
    • /backup/config.json — backup codes
    • /session — session info leak
    • /secret — hidden directory hint

    /login               Login form
    /register            Account registration
    /forgot-password     Password reset request

  Authenticated pages:
    /dashboard           Role-based dashboard
    /profile/:id         View profile (IDOR)
    /profile/:id/edit    Edit profile (mass assignment)
    /grades/:id          View grades (IDOR)
    /transcript/:id      View + edit transcript (IDOR)
    /courses             Course catalog
    /courses/enroll/:id  Enroll in a course

  Privileged pages (no role check):
    /admin               Admin panel
    /it/dashboard        IT dashboard
    /lecturer/grades     Grade management

  Vulnerable endpoints:
    /robots.txt          Credential leak
    /.env                Environment leak
    /backup/config.json  Backup config leak
    /backup/             Backup directory
    /secret/             Hidden directory
    /session             Session info
    /api/users           All users (no auth)
    /api/courses         All courses (no auth)
    /api/enrollments     All enrollments (no auth)
